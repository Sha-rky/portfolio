# Portfolio Website | 個人作品集網站

## Overview | 概述

This is a modern portfolio website built with Next.js, showcasing my professional work, skills, and experiences. The website features a clean, responsive design and optimal performance.

這是一個使用 Next.js 建立的現代化作品集網站，展示我的專業作品、技能和經驗。網站具有簡潔的響應式設計和最佳性能。

## Features | 功能特點

- 🎨 Modern and Clean Design | 現代簡潔的設計
- 📱 Fully Responsive | 完全響應式設計
- ⚡ Fast Performance | 快速性能
- 🌙 Dark/Light Mode | 深色/淺色模式
- 🎯 SEO Optimized | SEO 優化
- 📝 Blog Section | 部落格專區
- 📂 Project Showcase | 專案展示
- 📬 Contact Form | 聯絡表單

## Tech Stack | 技術棧

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Fonts**: Geist Sans & Geist Mono
- **Deployment**: Vercel
- **Content Management**: MDX
- **Animation**: Framer Motion
